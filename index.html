Como disponibilizar para as escolas sem custos:

Como o projeto usa apenas HTML, JS e Google Sheets, pode ser hospedado de forma 100% gratuita no GitHub Pages.

  1. Envie estes ficheiros (`index.html` e `script.js`) para o seu repositório no GitHub.
  2. Vá a Settings > Pages no repositório.
  3. Em Branch, selecione main e clique em Save.
  4. Partilhe o link gerado com as diretorias escolares!
